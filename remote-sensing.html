Chicago Vegetation & Satellite Remote Sensing

A Chicago-focused remote sensing project designed to compare vegetation conditions using NDVI and investigate differences across neighborhoods.

What is implemented?

The project folder includes Python code for NDVI calculation from Landsat red and near-infrared bands. NDVI = (NIR − Red) / (NIR + Red). It requires aligned, cloud-screened satellite images for valid change detection.

No Chicago satellite image has been processed in this package. I am not claiming observed vegetation loss or gain without source imagery.

How the next analysis works

Choose two cloud-free scenes from the same season, align spatial grids, mask clouds and shadows, calculate NDVI, and compare vegetation statistics. ChiVes also publishes Chicago tract-level NDVI and canopy variables for independent validation.

Research question

How could satellite observations help investigate vegetation in Chicago?

Scientific background

Remote sensing uses measurements from orbit to study the land surface. NDVI is a common indicator of vegetation greenness.

Method

I prepared a Python workflow for calculating NDVI from appropriately selected satellite bands.

Interpretation

The workflow is ready, but the satellite imagery has not yet been processed into verified findings.

Limitations

Next I plan to compare cloud screened images from comparable seasons and document uncertainty.
